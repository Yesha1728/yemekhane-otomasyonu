2. Uygulama yanit veriyor
============================================================
Komut: Api "Get" "/" | ConvertTo-Json

{
    "uygulama":  "Yemekhane Otomasyonu API",
    "durum":  "calisiyor"
}

Aciklama: Apache /api/ istegini Django uygulamasina iletti ve uygulama JSON ile yanit verdi.

5. Giris: dogru sifre
============================================================
Komut: (Api "Post" "/giris" @{ eposta = "mehmet.yildiz@ogr.kampus.edu.tr"; sifre = "Yemek2026!" }).kullanici | ConvertTo-Json

{
    "id":  7,
    "ad":  "Mehmet",
    "soyad":  "Yıldız",
    "eposta":  "mehmet.yildiz@ogr.kampus.edu.tr",
    "rol":  "ogrenci"
}
Aciklama: Dogru e-posta ve sifre ile giris yapildi; sifre ozeti (hash) asla gonderilmez, yalnizca kullanici bilgisi ve oturum jetonu doner.
